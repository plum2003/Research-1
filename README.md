# Research Learning Notes

This repository collects my early notes and small examples for research-oriented data work.

## Focus

- R basics for data analysis
- Data cleaning and summary statistics
- Simple research workflow notes
- Reproducible examples that are easy to review

## Contents

- `notes/01-data-cleaning.md`: basic data cleaning checklist
- `notes/02-basic-visualization.md`: notes on simple plots and when to use them
- `examples/basic-summary.R`: a small R script for summary statistics

## Why This Repository Exists

I am building practical GitHub habits while learning tools that support medical and research work. The goal is to keep each example small, readable, and useful for future open-source documentation or research-support contributions.
