# Basic Visualization Notes

Simple plots are often enough for a first look at a dataset.

## Common Choices

| Goal | Plot |
| --- | --- |
| Compare groups | Bar chart or boxplot |
| Show distribution | Histogram |
| Show relationship | Scatter plot |
| Show trend over time | Line chart |

## Good Habits

- Use clear titles.
- Label axes and units.
- Avoid unnecessary decoration.
- Keep one main message per chart.
