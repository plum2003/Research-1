# Data Cleaning Checklist

This note tracks a basic workflow for cleaning small research datasets in R.

## Checklist

- Check column names.
- Check data types.
- Look for missing values.
- Identify duplicate rows.
- Confirm units and coding rules.
- Create a short summary before analysis.

## Example Questions

- Are missing values coded consistently?
- Are numeric columns stored as numbers?
- Are categorical variables using clear labels?
- Is there a data dictionary or README?
